# Super Admin Web Application (`super-admin-web`)

A standalone executive command center for marketplace governance, brand moderation, buyer analytics, and catalog compliance.

## Key Features
- **Dedicated Secure Login**: Restricted login gateway (`/admin/login`) requiring administrative credentials.
- **Executive Overview**: Platform GMV, platform commission revenues, registered buyer counts, active brand count, and pending review counts.
- **Brand Seller Governance**:
  - Review brand registrations and business credentials (CIN, GSTIN, contacts).
  - Approve, suspend, or reactivate brand seller accounts.
  - Set custom commission rate overrides for individual brands.
- **Platform Buyers Directory**: Inspect buyer profiles, order frequencies, and lifetime spend.
- **Catalog Moderation**: Review all clothing pieces submitted by brands with Approve, Flag, or Reject actions and notes.
- **Global Order Oversight**: Complete ledger of multi-brand customer checkouts and settlement statuses.
- **Security Audit Trail**: Chronological event logs for administrative and brand operations.
