# Buyer Web Application (`buyer-web`)

The customer-facing e-commerce storefront for the **MINIMAL.** fashion marketplace.

## Key Features
- **Curated Storefront**: Browse apparel collections across all approved marketplace brands.
- **Search & Filters**: Filter by category, clothing type, fabric, fit, season, and price.
- **AI Fashion Stylist**: Slide-over AI shopping assistant for natural language outfit advice and recommendations.
- **Brand Directory**: Discover independent designers and atelier fashion brands (`/stores` or `/brands`).
- **Brand Storefronts**: Dedicated public storefronts for each brand (`/brands/:slug`).
- **Cart & Fast Checkout**: Full variant selection (size/color), atomic inventory checks, and payment processing.
- **Buyer Account Portal**: Track orders, view parcel tracking numbers, and initiate returns/exchanges.
- **Dual-Mode Auth**: Choice between Buyer Registration/Login and Brand Seller registration.
